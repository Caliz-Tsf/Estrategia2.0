# Imágenes de referencia — Confluencias

> Carpeta de entrada del usuario. Aquí se suben las capturas de gráficos que muestran
> **lo que se busca replicar**: estructura, conceptos SMC/ICT que se cumplen, y dónde
> se entra según el cumplimiento de esos conceptos.

## Propósito
- Fuente visual de verdad para el esqueleto Fase 4 (EA MT5) y para el enjambre.
- Foco de análisis (indicado por el usuario, S097):
  1. **La estructura** (dealing range, BOS/CHoCH/MSS, giros).
  2. **Los conceptos que se cumplen** en cada setup (OB, FVG, pools, P/D, etc.).
  3. **Dónde se entra** según el cumplimiento — recordando que las confluencias
     **no siempre se dan 100% exactas**: se lee atrás, se proyecta adelante a zonas,
     y se decide qué hacer al llegar (confirmar / entrar / invalidar / re-proyectar).

## Protocolo
- El usuario sube TODAS las imágenes aquí y avisa cuando termina.
- Claude/Fable las lee COMPLETAS antes de escribir cualquier esqueleto o análisis.
- Nomenclatura sugerida (no obligatoria): `NN-simbolo-tf-descripcion.png`
  (ej. `01-eurusd-h1-choch-ob-entrada.png`).
